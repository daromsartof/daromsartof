## 🧭 About me

I'm a full-stack and mobile developer who ships **complete products**, not demos — from the Expo app in the customer's hand to the Docker container running the API in production.

- 🛒 Currently building **BD Market**, an African grocery marketplace with its own delivery fleet (customer app, courier app, merchant back-office, admin hub)
- 🚚 And **Noïz Logistics**, a logistics platform (Express + Firebase API, React dashboard)
- 🏗️ I like **monorepos done right** — pnpm workspaces, Turborepo, shared design systems, typed domain packages
- 🤖 Also spend a lot of time on applied AI: **RAG pipelines, OCR, document classification, intelligent scraping**
- 🧰 Comfortable across the stack: TypeScript, Python and PHP; React, React Native, Next.js, FastAPI, Prisma, Firebase
- 📫 Reach me at **romeoerika.razaka@gmail.com**

## 🏗️ Product & Client Work

> Products built end-to-end for real users and clients. Most of these live in private repositories.

### 🛒 BD Market — African grocery marketplace & delivery

A full commerce ecosystem: customers order African groceries, merchants manage their shop, couriers deliver.

| App | Role | Stack |
| --- | --- | --- |
| **BD Market (mobile)** | Customer app — catalog, cart, delivery-fee engine, order tracking | Expo Router · React Native · Firebase · Codemagic |
| **BD Market Livreur** | Courier app — missions, live GPS, proof-of-delivery camera, OTA updates | Expo · expo-location · expo-camera · expo-updates |
| **BD Market Épicerie** | Merchant back-office — catalog, stock, order fulfilment | Vite · React · TypeScript · shadcn/ui |
| **BD Market Admin Hub** | Platform admin — merchants, fleet, catalog, encrypted ops data | Vite · React · Firebase · Playwright · `@noble/ciphers` |

### 🚚 Noïz Logistics

Logistics platform built as a pnpm monorepo — Express + `firebase-admin` API and a Vite/React admin dashboard, sharing types and Firestore indexes.

`pnpm workspaces` · `Express` · `Firebase Admin` · `React` · `TypeScript`

### 🏢 Daromsart Agency — Monorepo & design system

The agency platform: Turborepo + pnpm monorepo hosting Next.js products, a shared ShadCN design system (`@daromsart/ui`), shared Tailwind tokens (`@daromsart/theme`), shared configs, and Python FastAPI workers.

`Turborepo` · `Next.js` · `TypeScript` · `Vitest` · `Playwright` · `FastAPI` · `Docker`

- **InvoiceFlow AI** — invoicing SaaS with AI-assisted document handling

### 📱 ProConnect / ClicketPro & Ale

Turborepo monorepo hosting **two products on one shared backend**, each with its own database and deployment:

- **ClicketPro** — marketplace connecting clients with local artisans
- **Ale** — mobility super-app (ride-hailing, taxi, medical transport, delivery, carpooling)

`Next.js 16` · `Prisma` · `MySQL` · `Expo Router` · `Docker` · `GitHub Actions CI/CD`

### 🏥 Medical Transport

Medical transport management platform — missions, scheduling, patients, billing.

`Next.js` · `MUI` · `Prisma` · `NextAuth` · `FullCalendar` · `Docker`

### 🗂️ Business CRMs on the MAESTRA PHP framework

Modular, plugin-based PHP applications with their own migration tooling, deploy scripts and backup pipelines:

| Project | Domain |
| --- | --- |
| **G5 CRM** | CRM for the G5 training center |
| **Palmerimmo CRM + Portail** | Real-estate CRM, client portal and its Expo companion app |
| **Luximmo CRM** | Real-estate agency CRM |
| **Notete** | SaaS platform behind notete.com |
| **Just Home Portail** | Real-estate client portal |

`PHP (MAESTRA)` · `MySQL` · `Makefile tooling` · `Docker` · `Expo (WebView companion)`

### 🤖 MaestraLab

AI-agent SaaS with a built-in guidance/onboarding system.

### 🌐 Websites & E-commerce

**SOURCEA** (Madagascar sourcing office) · **G5 Formation** · **Luximmo** (v1 & v2) · **L'Ilot Chaussures** (e-commerce) · **Glass Dev Folio** (luxury creative-developer portfolio)

### 📲 Mobile side products

**Scan2Save** (scan & save deals) · **PureBudget** (personal budgeting, i18n, biometrics) · **Todo Improved** (Expo SDK 56, Google auth, Firestore) · **Musique App** · **Ranoko** (household water tracking, app + API)
